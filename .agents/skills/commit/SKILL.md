# commit — ドキュメント更新込みコミットスキル

「コードを変えたのに README や docs/features が古いまま」を防ぐのが本スキルの主目的。**コードとドキュメントは原則同じコミットで揃える**。

## 使うべきタイミング

- `/commit` と打たれた
- 「コミットして」「commit this」「これコミット」「いったん保存」「区切り」など、ユーザーが現在の作業を git に固定したい意図を示したとき
- 一連の編集が終わって「次の作業に行きたい」と読める文脈

## 使ってはいけないタイミング

- push / PR 作成（このスキルの責務外）
- 履歴改変（`--amend` / rebase）を求められた場合
- `git status` / `git diff` を見たいだけのとき

## フロー

コミット前にドキュメントを更新する
